# vacationTracker
Vacation tracker for analyse the team vacation impact per project


# dev container initialization guide


### 1. Install Dev Container Extension

   - Open VS Code
   - Press `ctrl` + `shift` + `x` to open Extensions panel
   - Search for Dev Containers and click to install


### 2. Start the project
   - Press `F1` to open the command pallette
   - Search and select for `Dev Containers: Clone Repository in Container Volume`
   - Select again the option `Clone Repository in Container Volume`
   - Paste the github repository url in the search bar
   - Press enter to confirm the clone
   - Wait for the build
